# 视频网格播放器 - V4.0 需求文档

## 1. 项目概述

本项目将"视频网格播放器"从一个本地文件预览工具，重构为一个基于云端的视频数据集管理与播放应用。应用的核心是 **Supabase** 后端，负责存储所有视频文件和元数据。前端则由两个核心视图（页面）构成：一个用于 **数据集管理** (`datasets.html`)，另一个用于 **视频播放** (`player.html`)。

## 2. 应用架构与导航

应用采用多页面架构，包含一个导航主页和两个核心功能页面。

### 2.1. 导航主页 (`index.html`)

*   **定位**: 应用的统一入口，为用户提供清晰的功能引导。
*   **内容**:
    *   应用标题和简介。
    *   两个大型引导卡片/按钮，分别链接到以下两个核心功能区：
        1.  **[数据集管理]** -> `datasets.html`
        2.  **[本地播放器]** -> `player.html` (此按钮为可选，主要用于快速预览本地文件，不与云端交互)

### 2.2. 全局导航栏

*   所有页面共享一个全局导航栏，提供一致的跨页面导航体验。

## 3. 核心页面与功能

### 3.1. 数据集管理页面 (`datasets.html`)

此页面是所有云端数据集的创建、浏览和内容管理中心，采用**两栏式布局**。

*   **左侧面板：数据集列表**
    *   **显示**: 从 Supabase 加载并以列表形式展示所有已存在的数据集。
    *   **创建**: 提供一个"+"按钮，允许用户输入名称来创建一个新的、空的云端数据集。
    *   **交互**: 用户可以点击列表中的任何数据集来在右侧面板中查看其内容。当前选中的数据集会被高亮显示。

*   **右侧面板：数据集内容**
    *   **标题**: 显示当前选定数据集的名称，并提供一个 **[删除数据集]** 按钮。
    *   **内容区**:
        *   **视频列表**: 显示当前选定数据集中所有已上传的视频文件列表。
        *   **上传功能**: 提供一个文件上传区域（可通过拖拽或点击选择），允许用户将视频文件**上传到当前选定的数据集**。
        *   **播放器入口**: 为每个数据集提供一个 **[在播放器中打开]** 的按钮，点击后将携带数据集ID跳转到播放器页面。

### 3.2. 播放器页面 (`player.html`)

此页面是指定云端数据集的**只读**播放视图。

*   **加载机制**:
    *   页面通过 URL 查询参数 `?dataset=<dataset_id>` 来识别要加载的数据集。
    *   如果 URL 中没有 `dataset_id`，则页面会显示提示信息，引导用户从"数据集管理"页面进入。
*   **功能**:
    *   从 Supabase 加载并以网格布局显示指定数据集中的所有视频。
    *   提供视频播放的基本控件。
    *   页面标题会显示当前数据集的名称。

## 4. 功能需求详述

### 4.1. 创建与填充数据集 (核心流程)

1.  用户进入 **数据集管理** 页面。
2.  点击左侧面板的"+"按钮，输入名称（如 "训练集A"），创建一个新的空数据集。
3.  新创建的 "训练集A" 出现在左侧列表中并被自动选中。
4.  右侧面板更新，标题显示 "训练集A"，并展示文件上传区域。
5.  用户将多个视频文件拖拽到上传区域。
6.  文件被逐个上传到 Supabase Storage，并将文件记录（URL、名称等）关联到 "训练集A" 的ID并存入数据库。
7.  上传完成后，视频文件列表出现在右侧面板中。

### 4.2. 播放数据集

1.  用户在 **数据集管理** 页面，选择一个已填充视频的数据集。
2.  点击 **[在播放器中打开]** 按钮。
3.  浏览器跳转到 `player.html?dataset=<dataset_id>`。
4.  播放器页面加载并显示该数据集的所有视频。

### 4.3. 删除数据集

1.  用户在 **数据集管理** 页面，选择一个数据集。
2.  点击右侧面板的 **[删除数据集]** 按钮，并进行二次确认。
3.  **后端处理**:
    *   **删除文件**: 从 Supabase Storage 中删除该数据集关联的所有视频文件。
    *   **删除记录**: 从 Supabase Database 中删除与该数据集相关的所有记录（包括数据集本身和其视频列表）。

## 5. 后端数据模型 (Supabase)

数据模型保持不变，包含 `datasets` 和 `videos` 两张表。

1.  **`datasets` 表**: 存储数据集信息。
    *   `id` (UUID, Primary Key)
    *   `name` (Text)
    *   `created_at` (Timestamp)

2.  **`videos` 表**: 存储视频信息并关联到数据集。
    *   `id` (UUID, Primary Key)
    *   `dataset_id` (UUID, Foreign Key -> `datasets.id`)
    *   `file_name` (Text)
    *   `storage_path` (Text)
    *   `public_url` (Text)

## 6. 非功能性需求

*   **无用户认证**: 应用是公开的，任何访问者都可以管理其配置的 Supabase 实例中的数据。
*   **数据隔离**: 所有数据（视频、元数据）完全存储在用户自己提供的 Supabase 项目中，实现了物理隔离和数据所有权。
