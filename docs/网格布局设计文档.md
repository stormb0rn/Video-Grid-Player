# 视频网格播放器 - 技术文档

## 项目概述

视频网格播放器是一个基于现代Web技术的轻量级应用，设计用于同时预览和管理多个视频文件。它采用网格布局，支持拖放操作、文件夹结构保留、视频过滤、截图和批量下载等功能。

## 核心技术

* **原生JavaScript**: 无框架依赖，使用原生DOM API
* **HTML5 视频API**: 用于视频预览和控制
* **拖放API**: 实现直观的文件上传
* **文件系统API**: 处理文件和文件夹
* **虚拟滚动**: 实现高性能的大量视频渲染
* **Canvas API**: 用于视频截图功能

## 性能优化

视频网格播放器采用了多种性能优化技术，以确保即使在处理大量视频文件时也能保持流畅的用户体验：

1. **虚拟滚动**:
   - 只渲染可见区域附近的视频
   - 超出可视范围的视频被替换为轻量级占位符
   - 减少内存占用和GPU负载

2. **懒加载**:
   - 视频资源在进入可视区域附近时才加载
   - 使用数据属性(data-src)存储视频URL
   - 不可见视频资源可以自动释放

3. **批量处理**:
   - 大量视频文件分批次处理
   - 处理间隔错开，避免浏览器假死
   - 显示处理进度提供良好的用户反馈

4. **资源回收**:
   - 监听页面可见性，页面不可见时暂停视频
   - 定期清理长时间不可见的视频资源
   - URL.revokeObjectURL释放不再需要的对象URL

## 视频性能优化配置

```javascript
const PERFORMANCE_CONFIG = {
  lazyLoadDistance: 300,      // 懒加载检测距离（像素）
  batchSize: 15,              // 每批处理的视频数量
  processingDelay: 50,        // 批处理间隔时间（毫秒）
  cleanupInterval: 30000,     // 自动清理不可见视频的间隔（毫秒）
  maxVisible: 50,             // 最大同时可见的视频数量
  virtualScrolling: true,     // 启用虚拟滚动
  usePlaceholders: true       // 使用占位符
};
```

## 功能实现

### 1. 拖放上传

用户可以通过拖放操作上传视频文件或文件夹。应用使用HTML5拖放API和文件系统API来处理这些操作。

关键代码:
```javascript
dropZone.addEventListener('drop', function(e) {
  e.preventDefault();
  e.stopPropagation();
  handleDrop(e);
}, false);
```

### 2. 文件夹结构保留

当用户上传整个文件夹时，应用会保留并显示原始的文件夹结构。这使用户可以更轻松地定位和组织他们的媒体文件。

### 3. 视频过滤

用户可以按类型过滤媒体文件，例如只显示视频而隐藏图片。过滤功能使用CSS和JavaScript实现，通过切换元素的显示属性。

### 4. 视频截图

用户可以为单个视频或所有视频截取当前帧作为图像。这使用Canvas API实现，可以将视频帧绘制到canvas上，然后导出为图像文件。

### 5. 批量下载

应用支持一键下载所有视频文件，方便用户将媒体文件保存到本地。

### 6. 云存储集成

通过Supabase集成，用户可以选择将媒体文件上传到云存储，实现跨设备访问和共享。

## 浏览器兼容性

视频网格播放器兼容所有现代浏览器，包括：

- Chrome 60+
- Firefox 55+
- Safari 11+
- Edge 16+

某些高级功能（如文件夹上传）可能在旧版浏览器中不可用。

## 部署说明

此应用可以部署在任何静态网站托管服务上，如Vercel、Netlify或GitHub Pages。

推荐设置:
- 使用CDN加速静态资源加载
- 启用HTTP/2以优化多文件并行加载
- 配置适当的缓存头以提高重复访问性能
