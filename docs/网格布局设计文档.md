# 视频网格播放器布局设计文档

## 1. 网格布局设计概述

视频网格播放器采用了响应式网格布局，能够自动适应不同设备屏幕大小和各种宽高比的视频/图片。设计目标是在保持视频/图片完整性和清晰度的同时，提供最优的空间利用和浏览体验。

## 2. 核心布局技术

### 2.1 CSS Grid 布局

```css
.files-grid {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(240px, 1fr));
  gap: 16px;
  width: 100%;
}
```

这段代码是网格布局的核心：

- `display: grid` - 启用 CSS Grid 布局
- `grid-template-columns: repeat(auto-fill, minmax(240px, 1fr))` - 自动填充策略:
  - `minmax(240px, 1fr)` - 每个单元格最小宽度 240px，最大可扩展分配剩余空间
  - `repeat(auto-fill)` - 浏览器自动计算可放置的列数
- `gap: 16px` - 网格单元格之间的间距

### 2.2 响应式设计原理

在不同屏幕尺寸下，网格布局会自动调整：

- **大屏设备**: 可能并排显示 4-5 个视频
- **中等屏幕**: 可能并排显示 2-3 个视频
- **移动设备**: 可能并排显示 1-2 个视频

这种调整完全由 CSS Grid 的自动填充机制控制，无需额外的媒体查询。

## 3. 视频/图片容器设计

### 3.1 容器结构

```html
<div class="video-container">
  <div class="video-wrapper">
    <video src="..."></video>
    <!-- 或 -->
    <img class="image-preview" src="...">
  </div>
  <div class="video-info">
    <!-- 文件名、路径等信息 -->
  </div>
</div>
```

### 3.2 容器样式

```css
.video-container {
  width: 100%;
  background: #1F1F1F;
  border-radius: 10px;
  overflow: hidden;
  display: flex;
  flex-direction: column;
  position: relative;
}

.video-wrapper {
  position: relative;
  width: 100%;
  background: #000;
  display: flex;
  justify-content: center;
}

video {
  max-width: 100%;
  max-height: 320px;
  width: auto;
  height: auto;
}

.image-preview {
  max-width: 100%;
  max-height: 320px;
  object-fit: contain;
  display: block;
}
```

关键样式特点：
- 容器宽度为网格单元格的 100%
- 内容最大高度限制为 320px
- 使用 `object-fit: contain` 确保内容完整显示不被裁剪
- 内容在容器中居中显示

## 4. 视频宽高比自适应逻辑

### 4.1 JavaScript 动态调整

```javascript
video.addEventListener('loadedmetadata', () => {
  // 计算视频宽高比
  const videoRatio = video.videoWidth / video.videoHeight;
  
  // 针对垂直视频（如手机录制）进行特殊处理
  if (videoRatio < 1) {
    // 垂直视频优先考虑宽度
    video.style.height = 'auto';
    video.style.width = '100%';
  }
});
```

该逻辑确保：
- 横向视频能够完整显示
- 竖向视频（宽高比 < 1）能够充分利用可用空间但不变形

### 4.2 不同设备兼容性考虑

- 在触摸设备上增加了适当的间距和触摸区域
- 支持暗色模式，优化夜间观看体验
- 提供操作反馈（如悬停效果、高亮当前视频等）

## 5. 滤镜和批量操作时的布局保持

当应用文件夹过滤或执行批量操作（如截图）时，维持相同的网格布局逻辑：

```javascript
function filterVideosByFolder(folderPath) {
  // ...筛选逻辑...
  
  // 创建新的网格容器
  const filteredGrid = document.createElement('div');
  filteredGrid.className = 'files-grid';
  
  // 填充筛选后的内容
  filteredVideos.forEach(container => {
    filteredGrid.appendChild(container.cloneNode(true));
  });
  
  // 替换现有网格
  videoGrid.innerHTML = '';
  videoGrid.appendChild(filteredGrid);
  
  // 重新附加事件监听器
  attachEventListenersToContainer(filteredGrid);
}
```

## 6. 性能优化策略

为确保大量视频下的流畅体验，采取了以下措施：

1. **懒加载**: 视频在用户查看前不会预加载
2. **延迟渲染**: 滚动到可视区域时才渲染完整内容
3. **内存管理**: 及时释放不再需要的资源（如 `URL.revokeObjectURL`）
4. **批处理**: 大量操作（如截图）时使用分批处理以避免界面冻结

## 7. 未来扩展性

当前布局设计支持以下潜在扩展：

- 增加更多视图模式（如列表视图、详情视图）
- 支持自定义单元格大小设置
- 增加排序和分组功能
- 集成更多媒体类型（如音频、文档等）

通过保持网格布局的核心原则不变，可以轻松实现这些扩展。
